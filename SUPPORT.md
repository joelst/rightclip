# Support

For installation, supported formats, output safety, and usage, start with
[README.md](README.md).

Use GitHub issues for reproducible bugs and feature requests. Include the
RightClip and Windows versions, the action you selected, and the complete error
message after redacting private paths and metadata.

Do not attach private videos. A small synthetic reproduction is preferable.
Codec/container limitations should include codec and container names rather than
the original media.

For development questions, see [CONTRIBUTING.md](CONTRIBUTING.md).
For vulnerabilities, use the private route in [SECURITY.md](SECURITY.md).

This is a community project with best-effort support, not a supported Microsoft
or FFmpeg product.
